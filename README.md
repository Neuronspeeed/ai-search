# Search Basics, Interactive

How a search engine finds pages and puts them in order, explained with live demos you can drag and click:
inverted indexes and BM25, click signals, knowledge graphs, learning to rank, dense vectors, hybrid fusion,
quantization, evaluation (NDCG, recall, MRR), RAG, and search for agents.

**Live site:** https://neuronspeeed.github.io/ai-search/

Every chart runs in the browser on small toy datasets. No build step and no dependencies beyond KaTeX (loaded from a CDN).

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
